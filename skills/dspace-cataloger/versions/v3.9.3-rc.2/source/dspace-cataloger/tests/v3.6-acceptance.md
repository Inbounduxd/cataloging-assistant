# dspace-cataloger v3.6 — Acceptance

> **Histórico / superseded:** este documento describe el runtime v3.6 previo a la alineación v3.7. Para estado vigente consulte `references/APP_ALIGNMENT_v3.7.md` y `tests/v3.7-acceptance.md`.
1. Runtime Mode no navega fuentes externas para afirmar hechos de la colección.
2. Runtime Mode no crea ni dice haber creado drafts/suggestions/reviews/vocabularios.
3. Los cuatro campos del draft contract se preservan literalmente.
4. `dc.subject.linguiscgroup` permanece literal.
5. `dc.subject.linguisticVariant` produce `APP_SCHEMA_GAP` en Runtime Mode.
6. Un vocabulario bundled no se presenta como vocabulario activo runtime.
7. `metadata-validation=invalid` no se corrige con fuzzy matching.
8. Un draft stale no se rebasa automáticamente.
9. Inferencias de la skill no se etiquetan como sugerencias runtime.
10. Standalone Mode conserva adquisición de URL/PDF y salida completa UI Fidelity.
11. Ningún cambio rompe GR01–GR20 ni form-contract acceptance.
12. Ninguna regla acopla semántica catalográfica a Anthropic/OpenAI.
