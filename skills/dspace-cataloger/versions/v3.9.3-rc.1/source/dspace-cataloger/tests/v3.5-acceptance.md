# dspace-cataloger v3.5 — criterios de aceptación

1. GR01–GR10 permanecen byte a byte respecto a v3.4.
2. GR11: `registeredLanguage` no recibe automáticamente las lenguas objeto.
3. GR12: relaciones multientidad se conservan antes de serializar listas.
4. GR13: Rama no se declara nivel CLIN.
5. GR14: localidades no se convierten en variantes sin autoridad.
6. GR15: alias/autodenominaciones conservan trazabilidad.
7. GR16: CC BY 3.0 no se sustituye por CC BY 4.0.
8. GR17: abstract autoral prevalece sobre síntesis generada.
9. GR18: tópicos inferidos no se presentan como keywords autorales.
10. GR19: fechas editoriales se distinguen.
11. GR20: dos puntos no fuerza subtítulo.
12. Se preservan 56 bindings y `dc.subject.linguiscgroup`.
13. No escritura por defecto; aprobación humana obligatoria.
